Why does the launcher resolve the executable with Get-AppxPackage instead of a path?

Because the Store rewrites the install directory on every update — the version is baked into the folder name. Resolving the package by identity survives that; a literal path breaks on the next release.

injector/core/preload.jsJavaScript
// D-0001-1 — official Electron API only; no debug port is ever opened.
const { app } = require('electron');
const theme = loadTheme(process.env.CDX_THEME);

app.on('browser-window-created', (_evt, win) => {
  win.webContents.on('dom-ready', () => {
    win.webContents.insertCSS(theme.css, { cssOrigin: 'user' });
  });
});

Texture: is it worth having at all?

The manifest slates three tiling textures — oak, leather, parchment — to sit behind the app's surfaces, which means behind your text. Here is the same panel under three treatments, on whichever ground you have selected above.

Grain strength
Grain tint

Panel 2's grain is generated procedurally here as a stand-in for the structure of a photographic texture — a fair test of how grain behaves at low opacity, an unfair test of how beautiful a real oak photograph would be.

My recommendation: cut the tiling textures

You called panel 2 noise, and that is the correct reading of it. Tiled grain is high-frequency variation, and on a flat UI surface the eye files high-frequency variation under "artifact," not "material." Our grounds make it worse: at 8–11% lightness there is no headroom to go darker, so grain can only lighten patches — which is exactly what a discolouration looks like.

There is also a hard engineering cost. Every contrast number on this page was computed against a flat colour. Put luminance variation behind body text and the figure that governs legibility is the worst pixel, not the average — so texture behind text makes AA un-provable. Readability is this project's first law, and a texture that cannot be proven safe loses to it.

Panel 3 is the alternative: material conveyed by light rather than by dirt. A large-scale warm gradient from above, a one-pixel brass catch on the top edge where light would strike, a darker lip at the bottom. All low-frequency, so it reads as a lit surface — and the luminance behind the text stays flat, so the AA numbers stay true. It is also pure CSS: nothing to generate, license, tile, or ship.

What we would keep. The hero behind the empty state — that one is meant to be seen, sits behind no dense text, and is where imagery earns its place. And the optional compass-rose crest, which was always hand-authored SVG. Everything else becomes CSS.

Two pairings

Both are SIL Open Font License 1.1 — free to bundle inside the .ccskin, commercially and otherwise, provided we ship the copyright notice and never sell the fonts alone. A font we could not legally redistribute was disqualified before it reached this page.

Pairing A — Ship's Log

Resolve the executable

Serif throughout. Fraunces carries the whole interface, dropping to its 14pt optical size for UI text so it stays crisp at 13px. Immersive — the app stops feeling like a browser.
