# Codexterity v0.3.1 — release notes

**Released 2026-09-27.** A small fix release: the empty-state hero image once again fills the whole
main panel on Codex `26.924.2738.0`. Project version `0.3.1` (`package.json`). Both themes' versions
stay `0.1.0`. No colour, font, scrim value or token name changed; only *where* the hero image paints.

As before, every claim below is either **verified** (something was run and observed) or **built but
unverified** (it exists, and nobody has watched it work).

---

## Why this release exists

Codex `26.924.2738.0` added a toolbar strip about 52px tall across the top of the main panel. It holds
the "New tab" button. The home screen's content area now starts *below* that strip, and that area is
where the hero image was painted. So the strip showed flat navy above the picture, and Codex's own
toolbar fade drew a dark seam where the two met. The owner spotted it in the running app. The theme
itself was loading correctly.

## What changed

- **The hero paints on the whole main panel**, including the new strip. It is still shown only on the
  empty home screen, never behind a conversation.
- **Codex's toolbar fade is hidden on the empty state only.** Over a photograph it read as a shadow
  line rather than a fade. Everywhere else it behaves as stock.
- **The header's floating buttons are inked with the primary text colour on the empty state.** With
  the image now under it, Codex's own colour for the "New tab" icon measured 1.38:1 in Deep Navy
  Portrait's dark mode, below the 3:1 an icon needs.
- The injector's startup log now reads "hero painting" off the panel, where the image actually is.

Recorded as an amendment to decision D-0001-9.

## Verified (Windows, this machine, Codex `26.924.2738.0`)

- Previewed live in the owner's running Codex: **Deep Navy Portrait** in dark and light, and
  **Captain's Cabin** in dark. The image reaches the top of the panel, the seam is gone, and the
  heading has not moved.
- **Contrast.** The scrims were not re-solved, and none needed to be. Deep Navy Portrait's single-alpha
  scrim is proven against the worst band anywhere in the image, so it already covers the new strip:
  **3.01:1 dark / 3.06:1 light** for the primary ink over the whole panel. Captain's Cabin's header
  button measures **16.49:1** where it sits. That figure is measured, not proven, because that
  theme's image is deliberately unveiled at the top.
- Installed from the built package. The owner launched through the Start-menu shortcut and confirmed
  it looks right.
- `npm test`: **410/410**. `audit.mjs`: **292/292**.

## Known gaps

- The portrait was not checked in a narrow, half-width window. How `cover` crops it there is
  unchanged from before, and the button's contrast is proven anywhere on the Deep Navy Portrait image.
- macOS: unverified, as in every release.
